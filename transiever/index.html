Export a Sieve script

No ManageSieve? Export supported rules to a local Sieve script for a provider that accepts one.

olrx export --rules outlook-rules.json
srtx generate --rules outlook-rules.json --sieve outlook.sieve

For Thunderbird, use tbrx export to create the rules file, then run the same srtx generate step. This workflow reads local client rules and writes local files; it needs no server credentials or ManageSieve connection.

Sync with confidence

Set your ManageSieve connection once, then run the adapter for your mail client.

TRANSIEVER_SIEVE_HOST=sieve.example.com
TRANSIEVER_SIEVE_USERNAME=user@example.com
TRANSIEVER_SIEVE_PASSWORD=secret

olrx run  # Outlook
tbrx run  # Thunderbird

Both commands show the result and ask before changing your server rules.
