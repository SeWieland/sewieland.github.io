Move your mail rules

Keep supported filters working when your mail client is closed. Start with a local export, then review before you sync.

  • Start with classic Outlook

    olrx requires configured classic Outlook on Windows x64.

  • Start with Thunderbird

    The read-only tbrx beta supports Windows x64 and Linux x64.

Build with .NET

Choose the layer your application needs. Both libraries target .NET 10 and have a short C# quickstart.

  • Generate Sieve with SieveRuler

    Model rules, render scripts, and add reconciliation and deployment workflows.

  • Connect with ManageSieve

    Use direct RFC 5804 protocol operations when your application owns the policy.

Check your provider before you sync

Sieve runs mail filters on the server. ManageSieve is the separate protocol for managing those scripts remotely.

No ManageSieve? Export a local Sieve script if your provider accepts one. Without Sieve support, your provider cannot run Transiever-generated rules.

AI usage

Transiever is a personal hobby project created to solve practical problems I have encountered myself.

AI is used heavily throughout its development. It supports research, design exploration, implementation, debugging, and documentation.

The project is developed using test-driven development and reviewed by a human, me. Its direction, behavior, and quality remain guided by the problems it is intended to solve.
