Transiever Sebastian Wieland

Put mail rules where the mail arrives.

Transiever is a small family of open-source tools for syncing and managing email rules on the server with Sieve and ManageSieve.

Choose the tool that fits

Windows x64

olrx

Sync supported classic Outlook receive rules to server-side Sieve.

Windows and Linux · Beta

tbrx

Sync supported Thunderbird filters to server-side Sieve.

Unstable beta — testers wanted

Windows and Linux

srtx

Generate, preview, deploy, and roll back provider-neutral JSON rules.

Windows and Linux

msieve

Inspect and manage server-side Sieve scripts directly through ManageSieve.

Install

Windows with Scoop

scoop bucket add transiever https://github.com/SeWieland/Transiever.ScoopBucket
scoop install transiever/olrx
scoop install transiever/tbrx
scoop install transiever/srtx
scoop install transiever/msieve

Linux x64 with Homebrew

brew install SeWieland/transiever/tbrx
brew install SeWieland/transiever/srtx
brew install SeWieland/transiever/msieve

olrx requires classic Outlook for Windows.

Sync in one command

Set your ManageSieve connection once, then run the adapter for your mail client.

TRANSIEVER_SIEVE_HOST=sieve.example.com
TRANSIEVER_SIEVE_USERNAME=user@example.com
TRANSIEVER_SIEVE_PASSWORD=secret

olrx run  # Outlook
tbrx run  # Thunderbird

Both commands preview the result and ask before deploying.
